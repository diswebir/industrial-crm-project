# 🏭 سامانه یکپارچه مدیریت مشتریان و دستگاه‌های صنعتی (Industrial Devices CRM)

**نسخه جاری: `v2.0.0`** — شماره نسخه ماشینی در فایل [`VERSION`](VERSION) و تاریخچه کامل تغییرات در [`CHANGELOG.md`](CHANGELOG.md)

سامانه مدیریت ارتباط با مشتریان (CRM) طراحی‌شده برای شرکت‌های تولیدکننده دستگاه‌های فیزیکی و صنعتی، شامل کاتالوگ دستگاه، انبارداری و کنترل موجودی، تخصیص دستگاه به مشتری با سریال یکتا و فاکتور، گارانتی و سرویس‌های دوره‌ای اختیاری، نقش‌های سازمانی با دامنه دسترسی دانه‌ای به مشتریان (RBAC + Pure ACL)، یکپارچگی با وب‌سرویس ملی‌پیامک و ورود/خروج اکسل چندشیته.

## 🟢 استقرار روی هاست cPanel (بدون SSH) — روش اصلی

بسته استقرار شامل دو فایل مستقل `cpanel-public.zip` و `cpanel-private.zip` است. مسیر خصوصی در `private-path.php` قابل تنظیم است؛ برای مثال فایل‌های عمومی در `/home/USER/xx.example.com` و هسته خصوصی در `/home/USER/private_pro/project1/myc` قرار می‌گیرند.

- ساخت بدون SSH روی هاست: از GitHub Actions → **cPanel package** → Run workflow و دانلود artifact استفاده کنید.
- ساخت محلی: `bash deploy/cpanel/build.sh` (نیازمند PHP/Composer و Node 22.12+ روی ماشین ساخت).
- نصب: ویزارد فارسی `install.php`، انتخاب اطلاعات مدیر اختصاصی و ایجاد قفل دائمی نصب.
- آموزش کامل ساخت محلی روی ویندوز و آپلود مستقیم به هاست: [`WINDOWS-BUILD-GUIDE.fa.md`](deploy/cpanel/WINDOWS-BUILD-GUIDE.fa.md) — lock فعلی به PHP 8.4.1+ نیاز دارد.
- راهنمای کامل و ارتقا: [`deploy/cpanel/README.md`](deploy/cpanel/README.md)
- **ارتقا از نسخه ۱ به `v2.0.0` روی هاست بدون از دست رفتن داده:** [`deploy/cpanel/UPGRADE-v2.0.0.fa.md`](deploy/cpanel/UPGRADE-v2.0.0.fa.md)
- اسکریپت خام SQL برای phpMyAdmin: [`deploy/cpanel/database/v2.0.0-mysql.sql`](deploy/cpanel/database/v2.0.0-mysql.sql)
- سند طراحی و برنامه ارتقا: [`docs/UPGRADE-PLAN-v2.0.0.fa.md`](docs/UPGRADE-PLAN-v2.0.0.fa.md) — گزارش پذیرش: [`docs/ACCEPTANCE-REPORT-v2.0.0.fa.md`](docs/ACCEPTANCE-REPORT-v2.0.0.fa.md)

## ⚙️ معماری سیستم و پشته فناوری

### فرانت‌اند (`/frontend`)
- **React 19 + TypeScript + Vite**
- **Tailwind CSS v4 + DaisyUI**: استایل‌دهی مدرن با تم‌های تیره و روشن (Dark/Light Mode) و سازگاری کامل با راست‌به‌چپ (RTL)
- **TanStack React Query v5**: مدیریت کش و درخواست‌های بهینه‌سازی‌شده
- **Zustand**: مدیریت استیت احراز هویت و دسترسی‌های کاربر
- **Lucide React**: آیکون‌های باکیفیت و هماهنگ

### بکند (`/backend`)
- **Laravel 11 (PHP 8.4)**
- **Filament v3**: پنل مدیریت کامل و فارسی برای مدیریت دیتابیس در `/admin`
- **PostgreSQL 15 (محلی) / MySQL 8 (هاست cPanel)**: دیتابیس رابطه‌ای امن با ایندکس‌های بهینه
- **Laravel Sanctum**: احراز هویت توکن‌محور (آماده اتصال ورود پیامکی OTP)
- **Spatie Laravel Permission**: پیاده‌سازی مدل مجوز مستقیم (Direct ACL Permissions) به‌همراه نقش سازمانی و دامنه دسترسی دانه‌ای به مشتریان
- **Dedoc Scramble**: تولید خودکار و زنده مستندات OpenAPI در `/docs/api`
- **Maatwebsite Excel**: برون‌بری دوشیته و درون‌ریزی فایل‌های `.xlsx` مشتریان
- **وب‌سرویس ملی‌پیامک (Melipayamak Service)**: ارسال پیامک‌های خدماتی و الگو (`BaseServiceNumber`) با حالت سندباکس و لاگ کامل در دیتابیس

## 📦 ویژگی‌های کلیدی کسب‌وکار

1. **مدیریت دستگاه‌های فیزیکی، موجودی انبار و شماره سریال یکتا:**
   - ثبت دستگاه‌ها در کاتالوگ با فیلدهای `name`، `code`، `periodic_service_months`، موجودی انبار (`stock_quantity`)، حد هشدار (`min_stock_quantity`) و توضیحات.
   - تخصیص دستگاه فیزیکی به مشتری به همراه **شماره سریال یکتا**، تعداد، شماره و مبلغ فاکتور (`serial_number`)، تاریخ نصب و محاسبه خودکار تاریخ پایان گارانتی.

2. **تبدیل خودکار مشتری بالقوه به بالفعل:**
   - مشتریان ابتدا می‌توانند به عنوان **«بالقوه» (potential)** تعریف شوند.
   - به محض تخصیص اولین دستگاه فیزیکی به مشتری، سیستم وضعیت او را به صورت خودکار به **«بالفعل» (effective)** ارتقا داده و در تاریخچه اقدامات مشتری لاگ می‌زند.

3. **سوابق سرویس و تعمیرات (گارانتی اختیاری):**
   - سرویس دوره‌ای به صورت اجباری یا یادآور خودکار نیست؛ بلکه یک پوشش گارانتی اختیاری از سمت شرکت است.
   - امکان ثبت سوابق تعمیر یا سرویس هر دستگاه تخصیص‌داده‌شده با فیلدهای نوع سرویس، تاریخ، هزینه، نام تکنسین و توضیحات کامل.

4. **نقش‌های سازمانی + مجوزهای مستقیم (RBAC + Pure ACL):**
   - چهار نقش سازمانی: «مدیر ارشد سامانه» (`administrator`)، «مدیر-سرپرست» (`manager`)، «کارمند فروش» (`salesperson`) و «نصاب» (`installer`). هر نقش مجموعه‌ای پیش‌فرض از مجوزها و دامنه دسترسی دارد که مدیر می‌تواند دستی تغییر دهد.
   - ۱۶ مجوز مستقیم تفکیک‌شده (کلید مجوزها در دیتابیس ثابت مانده‌اند تا دسترسی‌های فعلی از بین نروند؛ فقط برچسب فارسی آن‌ها «دستگاه» شده است):
     `customers.view`, `customers.create`, `customers.edit`, `customers.delete`, `customers.import`, `customers.export`, `parts.view`, `parts.manage`, `parts.assign`, `parts.history`, `inventory.manage`, `inventory.logs`, `sms.send`, `sms.logs`, `users.manage`, `settings.manage`
   - **دامنه دسترسی به مشتریان:** «همه مشتریان سامانه» (`all`) یا «فقط مشتریان خودش + استثناهای اعطاشده» (`own`). در حالت `own` مدیر می‌تواند دسترسی به «مشتریانِ یک یا چند کارمند مشخص» و «چند مشتری تکی» را اعطا کند.
   - امکان فعال/غیرفعال کردن کاربر، تخصیص مستقیم چک‌باکسی مجوزها و ویرایش دامنه دسترسی بدون خروج کاربر از سامانه.

5. **مرکز پیامک و اتصال به ملی‌پیامک:**
   - پشتیبانی از وب‌سرویس الگوی خدماتی (`BaseServiceNumber`).
   - تنظیم نام کاربری، رمز عبور، شماره خط و وضعیت آزمایشی (Sandbox) در تب تنظیمات بدون نیاز به کدنویسی.
   - لاگ تمام پیامک‌های ارسالی با وضعیت تحویل، شناسه پیامک و ارتباط با مشتری.

6. **اکسل مشتریان:**
   - امکان دانلود فایل نمونه اکسل جهت پر کردن داده‌ها (`/api/v1/customers/template`).
   - آپلود و ورود دسته‌ای مشتریان با گزارش جداگانه «خطاها» و «هشدارها» برای هر ردیف، به‌همراه شمارش رکوردهای **ساخته‌شده** و **به‌روزشده** (تشخیص تکراری بر پایه موبایل / کد ملی / شناسه ملی شرکت).
   - خروجی‌گیری زنده و دانلود اکسل **دوشیته** کلیه مشتریان (`/api/v1/customers/export`): شیت «مشتریان» (اطلاعات پایه + خلاصه دستگاه‌ها + جمع مبالغ فاکتور) و شیت «دستگاه‌های تخصیص‌یافته» (یک ردیف برای هر تخصیص).
   - خروجی محدود به دامنه دسترسی کاربر است؛ سرستون‌ها فارسی و راست‌به‌چپ و اعداد به‌صورت عددی ثبت می‌شوند.

7. **انبارداری و کنترل موجودی دستگاه‌ها (جدید در `v2.0.0`):**
   - موجودی هر دستگاه در کاتالوگ (`stock_quantity`) و حد هشدار کمبود (`min_stock_quantity`) با برچسب واحد دلخواه (پیش‌فرض «عدد»).
   - ثبت دستی «ورود کالا»، «خروج»، «برگشت به انبار» و «اصلاح موجودی» با تاریخ، مرجع (شماره فاکتور/سریال) و توضیحات.
   - تاریخچه کامل و حسابرس‌پذیر در جدول `inventory_logs` با ثبت موجودی قبل/بعد و کاربر انجام‌دهنده، به‌همراه فیلترهای دستگاه، نوع عملیات، مشتری، کاربر و بازه تاریخ.
   - موجودی هرگز منفی نمی‌شود: کسر موجودی داخل `DB::transaction` با قفل ردیف (`lockForUpdate`) و گارد به‌روزرسانی شرطی در برابر تغییر همزمان.
   - تخصیص/ویرایش/حذف دستگاه برای مشتری به‌صورت خودکار لاگ انبار (`out` / `return`) ثبت می‌کند.
   - گزارش «مغایرت انبار» برای مقایسه موجودی ثبت‌شده با جمع تخصیص‌ها (`/api/v1/inventory/reconciliation`).

8. **مدیریت کامل دستگاه‌های تخصیص‌یافته به مشتری (جدید در `v2.0.0`):**
   - تعداد، شماره فاکتور و مبلغ فاکتور (اختیاری) برای هر تخصیص؛ نمایش مبالغ با فرمت پولی فارسی (تومان).
   - ویرایش و حذف تخصیص دستگاه و همچنین ویرایش و حذف سابقه سرویس، هم از API و هم از تب «دستگاه‌های فیزیکی و سوابق خدمات» در پروفایل مشتری.
   - محاسبه خودکار تاریخ پایان گارانتی از تاریخ نصب + دوره سرویس دستگاه.

9. **مشتری حقیقی و حقوقی با اعتبارسنجی دقیق (جدید در `v2.0.0`):**
   - مشتری **حقوقی** فقط با «نام شرکت» و بدون نام/نام خانوادگی/موبایل قابل ثبت است؛ مشتری **حقیقی** با نام و نام خانوادگی اجباری و کد ملی ۱۰ رقمی.
   - عنوان نمایشی، جستجو، ورودی و خروجی اکسل همگی مشتریان حقوقیِ بدون نام شخصی را درست پوشش می‌دهند.

10. **تجربه کاربری فارسی یکدست (جدید در `v2.0.0`):**
   - فونت `Vazirmatn FD` (ارقام فارسی) به‌صورت لوکال و بدون CDN در فرانت‌اند و پنل Filament.
   - تقویم شمسی با پاپ‌آپ Portal که داخل مودال‌ها بریده نمی‌شود.
   - واژگان سراسری سامانه از «قطعه/قطعات» به «دستگاه/دستگاه‌ها» تغییر یافته است.

## 🐳 دستورات راه‌اندازی با داکر (Docker Compose)

### اجرای پروژه
```bash
docker compose up -d
```

### بررسی وضعیت کانتینرها
```bash
docker compose ps
```

### مشاهده لاگ‌های بکند
```bash
docker logs -f crm_backend
```

### توقف کانتینرها
```bash
docker compose down
```

### اجرای مجدد مایگریشن‌ها و سیدرها در صورت نیاز
```bash
docker exec -it crm_backend php artisan migrate:fresh --seed
```
