## 🟢 استقرار روی هاست cPanel (بدون SSH) — روش اصلی

بسته استقرار شامل دو فایل مستقل `cpanel-public.zip` و `cpanel-private.zip` است. مسیر خصوصی در `private-path.php` قابل تنظیم است؛ برای مثال فایل‌های عمومی در `/home/USER/xx.example.com` و هسته خصوصی در `/home/USER/private_pro/project1/myc` قرار می‌گیرند.

- ساخت بدون SSH روی هاست: از GitHub Actions → **cPanel package** → Run workflow و دانلود artifact استفاده کنید.
- ساخت محلی: `bash deploy/cpanel/build.sh` (نیازمند PHP/Composer و Node 22.12+ روی ماشین ساخت).
- نصب: ویزارد فارسی `install.php`، انتخاب اطلاعات مدیر اختصاصی و ایجاد قفل دائمی نصب.
- آموزش کامل ساخت محلی روی ویندوز و آپلود مستقیم به هاست: [`WINDOWS-BUILD-GUIDE.fa.md`](deploy/cpanel/WINDOWS-BUILD-GUIDE.fa.md) — lock فعلی به PHP 8.4.1+ نیاز دارد.
- راهنمای کامل و ارتقا: [`deploy/cpanel/README.md`](deploy/cpanel/README.md)
- وضعیت بررسی و محدودیت‌های آزمون: [`deploy/cpanel/AUDIT.md`](deploy/cpanel/AUDIT.md)

## ⚙️ معماری سیستم و پشته فناوری

### فرانت‌اند (`/frontend`)
- **React 19 + TypeScript + Vite**
- **Tailwind CSS v4 + DaisyUI**: استایل‌دهی مدرن با تم‌های تیره و روشن (Dark/Light Mode) و سازگاری کامل با راست‌به‌چپ (RTL)
- **TanStack React Query v5**: مدیریت کش و درخواست‌های بهینه‌سازی‌شده
- **Zustand**: مدیریت استیت احراز هویت و دسترسی‌های کاربر
- **Lucide React**: آیکون‌های باکیفیت و هماهنگ

### بکند (`/backend`)
- **Laravel 11 (PHP 8.4)**
- **Filament v3**: پنل مدیریت کامل و فارسی برای مدیریت دیتابیس در `/admin`
- **PostgreSQL 15**: دیتابیس رابطه‌ای امن با ایندکس‌های بهینه
- **Laravel Sanctum**: احراز هویت توکن‌محور (آماده اتصال ورود پیامکی OTP)
- **Spatie Laravel Permission**: پیاده‌سازی مدل مجوز مستقیم (Direct ACL Permissions) بدون تعریف نقش (Role)
- **Dedoc Scramble**: تولید خودکار و زنده مستندات OpenAPI در `/docs/api`
- **Maatwebsite Excel**: برون‌بری و درون‌ریزی فایل‌های `.xlsx` مشتریان
- **وب‌سرویس ملی‌پیامک (Melipayamak Service)**: ارسال پیامک‌های خدماتی و الگو (`BaseServiceNumber`) با حالت سندباکس و لاگ کامل در دیتابیس

## 📦 ویژگی‌های کلیدی کسب‌وکار

1. **مدیریت دستگاه‌ها، تعداد و فاکتور:**
   - ثبت دستگاه‌ها در کاتالوگ با فیلدهای `name`، `code`، `periodic_service_months`، موجودی انبار و توضیحات.
   - تخصیص دستگاه به مشتری با **تعداد**، شماره سریال اختیاری یکتا (`serial_number`)، **شماره و مبلغ فاکتور**، تاریخ نصب و محاسبه خودکار تاریخ پایان گارانتی.
   - ویرایش و حذف کامل تخصیص دستگاه از پروفایل مشتری با اصلاح خودکار موجودی انبار.

2. **تبدیل خودکار مشتری بالقوه به بالفعل:**
   - مشتریان ابتدا می‌توانند به عنوان **«بالقوه» (potential)** تعریف شوند.
   - به محض تخصیص اولین دستگاه به مشتری، سیستم وضعیت او را به صورت خودکار به **«بالفعل» (effective)** ارتقا داده و در تاریخچه اقدامات مشتری لاگ می‌زند.

3. **سوابق سرویس و تعمیرات (گارانتی اختیاری):**
   - سرویس دوره‌ای به صورت اجباری یا یادآور خودکار نیست؛ بلکه یک پوشش گارانتی اختیاری از سمت شرکت است.
   - امکان ثبت سوابق تعمیر یا سرویس هر دستگاه تخصیص‌داده‌شده با فیلدهای نوع سرویس، تاریخ، هزینه، نام تکنسین و توضیحات کامل.

4. **کنترل دسترسی (RBAC + Pure ACL):**
   - نقش‌های کاربری: مدیر ارشد، مدیر، **کارمند فروش** و **نصاب** (ستون `users.user_type`).
   - دامنه دسترسی مشتری با `users.data_scope`: `all` (همه)، `own` (فقط مشتریان خودش) و `custom` (خودش + استثناها).
   - جدول `customer_access_grants` برای اعطای استثنا: مشتریان یک کارمند دیگر یا مشتریان خاص.
   - اعمال محدودیت در **سرور** (کوئری‌ها، جزئیات، ویرایش، حذف، خروجی و داشبورد) و هم‌زمان در UI.
   - ۱۸ مجوز مستقیم تفکیک‌شده شامل مجوزهای جدید:
     `parts.assign.edit`, `parts.assign.delete`, `inventory.view`, `inventory.manage`
   - امکان فعال/غیرفعال کردن هر کاربر و تخصیص مستقیم چک‌باکسی دسترسی‌ها.

5. **انبار و لاگ کامل ورود/خروج:**
   - موجودی هر دستگاه در کاتالوگ، حد هشدار موجودی و کسر خودکار هنگام تخصیص.
   - برگشت خودکار موجودی هنگام حذف تخصیص یا کاهش تعداد.
   - ثبت تراکنش‌های دستی ورود، خروج و اصلاح موجودی (انبارگردانی).
   - جدول `inventory_logs` با نوع (`in | out | return | adjust`)، تعداد، موجودی بعد از تراکنش، نام ثبت‌کننده، مشتری مرتبط، توضیح و زمان دقیق.
   - صفحه اختصاصی «انبار و تاریخچه ورود/خروج» با کارت‌های خلاصه، فیلتر و لینک به پرونده مشتری.
   - جلوگیری از موجودی منفی با تراکنش دیتابیس و قفل ردیف.

6. **مرکز پیامک و اتصال به ملی‌پیامک:**
   - پشتیبانی از وب‌سرویس الگوی خدماتی (`BaseServiceNumber`).
   - تنظیم نام کاربری، رمز عبور، شماره خط و وضعیت آزمایشی (Sandbox) در تب تنظیمات بدون نیاز به کدنویسی.
   - لاگ تمام پیامک‌های ارسالی با وضعیت تحویل، شناسه پیامک و ارتباط با مشتری.

6. **اکسل مشتریان:**
   - امکان دانلود فایل نمونه اکسل جهت پر کردن داده‌ها (`/api/v1/customers/template`).
   - آپلود و ورود دسته‌ای مشتریان با گزارش خطاهای ردیف به ردیف.
   - خروجی‌گیری زنده و دانلود اکسل کلیه مشتریان (`/api/v1/customers/export`).

## 🐳 دستورات راه‌اندازی با داکر (Docker Compose)

### اجرای پروژه
```bash
docker compose up -d
```

### بررسی وضعیت کانتینرها
```bash
docker compose ps
```

### مشاهده لاگ‌های بکند
```bash
docker logs -f crm_backend
```

### توقف کانتینرها
```bash
docker compose down
```

### اجرای مجدد مایگریشن‌ها و سیدرها در صورت نیاز
```bash
docker exec -it crm_backend php artisan migrate:fresh --seed
```

```
├── docker-compose.yml           # کانفیگ چندکانتینری (بکند، فرانت، پستگرس، ردیس)
├── backend/                     # پروژه بکند لاراول ۱۱
│   ├── app/
│   │   ├── Http/Controllers/Api/V1/ # کنترلرهای RESTful
│   │   ├── Models/             # مدل‌های Customer, Part, CustomerPart, ServiceHistory, SmsLog, User
│   │   ├── Services/           # سرویس مشتریان و سرویس ملی‌پیامک
│   │   └── Exports/ & Imports/ # فایل‌های پردازش اکسل
│   ├── config/scramble.php     # تنظیمات مستندات OpenAPI
│   ├── database/migrations/    # مایگریشن‌های پایگاه‌داده و سیدر اولیه
│   └── routes/api.php          # اندپوینت‌های نسخه ۲ API
└── frontend/                    # پروژه فرانت‌اند ری‌اکت ۱۹
    ├── src/
    │   ├── components/         # کامپوننت‌های فرم، تخصیص دستگاه، انبار، سابقه سرویس و اکسل
    │   ├── layouts/            # سایدبار و لایوت اصلی با کنترل ACL
    │   ├── pages/              # داشبورد، مشتریان، قطعات، پیامک، تنظیمات، لاگین
    │   ├── services/api.ts     # اینترفیس تایپ‌شده Axios
    │   ├── store/useAuthStore.ts # مدیریت دسترسی‌ها و توکن Sanctum
    │   └── types/index.ts      # تایپ‌های کامل TypeScript
    ├── nginx.conf              # وب‌سرور Nginx فرانت‌اند و Reverse Proxy به بکند
    └── Dockerfile              # داکرفایل فرانت‌اند
```
